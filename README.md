# LEGION — Web Prototype 0.1

Первый рабочий прототип Legion.

## Сейчас реализовано

- Dark anime-inspired визуальный стиль
- Главное меню
- Играбельное поле «три в ряд» 8×8
- 6 типов элементов
- Комбинации 3+
- Цепные реакции и комбо
- Очки и 30 ходов
- Профиль, XP и статистика
- Локальное сохранение прогресса
- Настройки музыки, эффектов, вибрации и качества
- Коллекция — заглушка
- Турниры — заглушка

## Пока намеренно отсутствует

- Онлайн
- Рейтинг
- Legion Coin
- Реальные деньги
- Рынок
- Вывод средств
- Серверная экономика

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
```

## План

Сначала тестируем саму игру и визуал. После этого итеративно меняем механику и интерфейс. Когда базовая игра будет устраивать, добавляем аккаунты, сервер, онлайн, турниры, коллекцию и только потом экономику.
